Hexo部署避雷

Hexo部署避雷

配置_config.yml（站点配置）

在 Hexo根目录(有source、node_modules、scaffolds、themes等目录的地方)下，打开_config.yml，添加：

url: https://你的用户名.github.io # 也一定要改成这样，不然会出奇怪的bug

deploy:
  type: git
  repo: https://github.com/你的用户名/你的用户名.github.io.git
  branch: main  # 或 gh-pages, master，根据你自己设定的而定

检查 GitHub Pages 设置

Settings → Pages → Build and deployment → Source，选择对应分支（如 main, master, gh-pages），然后保存

构建+部署

于Hexo根目录右键打开 Open Git Bash here

hexo clean && hexo deploy

这会清理旧资源，生成静态文件，并将public/推送到你配置的branch上。

部署成功会打印显示INFO Deploy done: git

验证效果

打印显示成功后，等几分钟，访问：

  • 用户页：https://username.github.io/
  • 项目页：https://username.github.io/项目名/

如显示 404，检查是否为：

  • .nojekyll 文件缺失（跳过 Jekyll 的编译）
  • public/ 没生成 index.html
  • repo/branch 设置错误。

Ubuntu vs Windows for Dev

Will:

为什么一些搞科技的大公司都喜欢用ubuntu系统作为开发者主要使用的系统？而不是Windows？

ChatGPT:

许多科技公司选择 Ubuntu 作为开发者主要使用的系统，而不是 Windows，主要有以下几个原因：

1. 兼容性和开发环境

  • 服务器环境一致性：大多数服务器运行的是 Linux（特别是 Ubuntu Server 或 Debian-based 系统），开发者在本地使用 Ubuntu 可以减少环境差异，避免 “works on my machine”（在我电脑上能跑，但服务器上不行）的问题。
  • 原生支持开发工具：许多编程语言和开发工具，如 Python、C++、GCC、Clang、Docker、Kubernetes 等，在 Linux 上更稳定，并且很多库和依赖默认都是 Linux 优先支持。

2. 高度可定制性

  • Ubuntu 允许开发者自由修改和优化系统，而 Windows 对底层改动限制较多。
  • 可以通过 命令行（bash/zsh） 高效管理系统和开发环境，Linux 的 shell 远比 Windows 的 CMD 或 PowerShell 强大。

3. 更高效的资源管理

  • 占用资源更少：Ubuntu 比 Windows 轻量级，内存、CPU 占用更少，适合长时间运行编译任务、AI 训练等高负载任务。
  • 更强的多进程管理：Linux 进程管理比 Windows 稳定，尤其适合 后台任务 和 容器化部署。

4. 开源免费，减少企业成本

  • 企业可以自由定制，无须支付 Windows 许可证费用，特别是大规模部署时，节省成本。
  • 开源特性使得企业可以对系统进行深度优化，比如 Google 自己改造了 Ubuntu，做成了 Google 内部的开发系统 gLinux。

5. 开发者生态支持

  • AI/ML 相关框架优先支持 Linux：如 TensorFlow、PyTorch 在 Linux 运行更稳定，CUDA（NVIDIA GPU 加速）在 Linux 上支持更好。
  • 开源社区活跃，开发者可以获取 更快的更新 和 更好的社区支持，不像 Windows 受限于微软的更新周期。

6. Windows 的局限性

  • WSL 仍然有兼容性问题：虽然 Windows 现在有 WSL (Windows Subsystem for Linux)，但和原生 Linux 还是有差距，某些进程管理、权限系统、文件系统操作等仍然不够流畅。
  • 封闭生态和不必要的功能：Windows 自带的 GUI 界面、自动更新、后台进程管理等，可能会干扰开发工作，导致不必要的资源消耗。

结论

对于科技公司来说，Ubuntu 提供了更好的开发体验、更好的服务器兼容性、更低的成本和更强的可定制性，因此成为了很多大厂的首选。Windows 主要适合普通用户、办公和游戏，但在专业开发领域（特别是后端、AI、嵌入式等），Ubuntu 甚至是整个 Linux 生态都更有优势。

ubuntu系统为什么我在点击dock里面的一个应用的时候，它并不会像在windows系统里面那样，所有打开的页面都会到最上面来？就是说如果我开了多个页面的话，我点击dock里面的应用，只会有一个到前面来，我该如何解决这个问题呢？

ChatGPT:

在 Ubuntu 的默认 GNOME 桌面环境 下，点击 Dock 里的应用图标时，它只会激活（切换到前台）最近使用的一个窗口，而不是像 Windows 任务栏 那样把所有该应用的窗口都切换到前台。

解决方案

你可以使用以下方法来改进这一行为：

方法 1：使用鼠标滚轮切换多个窗口

如果该应用有多个窗口，在 Dock 上的应用图标上滚动鼠标滚轮，就可以依次切换不同的窗口。

方法 2：启用“点击应用图标显示所有窗口”

你可以修改 GNOME 的行为，使得点击应用图标时，显示所有该应用的窗口，类似于 Windows：

  1. 打开终端（Ctrl + Alt + T）。
  2. 输入以下命令：
    gsettings set org.gnome.shell.extensions.dash-to-dock click-action 'spread'
  3. 回车后，你点击 Dock 里的应用时，就会显示所有该应用的窗口（类似 Windows 任务栏的“缩略图预览”）。

如果想恢复默认行为：

gsettings reset org.gnome.shell.extensions.dash-to-dock click-action

方法 3：Alt + Tab 或 Alt + `（反引号）

  • Alt + Tab：在所有应用窗口之间切换（和 Windows 一样）。
  • Alt + （反引号，Tab 上面的键）：在 同一个应用 的多个窗口之间切换（相当于 Windows Alt + Tab 里的同应用切换）。

方法 4：安装 GNOME Tweaks（优化工具）

如果你想要更详细的自定义：

  1. 安装 GNOME Tweaks：
    sudo apt install gnome-tweaks
  2. 打开 Tweaks，找到 Extensions（扩展），然后调整 Dash to Dock 的设置。
  3. 在 Click Action 里选择 ‘Cycle through windows’ 或 ‘Previews’。

总结

  • 临时切换窗口 → Alt + Tab 或 Alt + （反引号）。
  • 鼠标滚轮 → 在 Dock 上滚动鼠标滚轮切换该应用的窗口。
  • 修改 GNOME 默认行为 → 运行 gsettings set org.gnome.shell.extensions.dash-to-dock click-action 'spread'，点击应用图标时显示所有窗口。
  • 安装 GNOME Tweaks 进行更细节调整。

如果你经常遇到这种问题，建议直接 方法 2，让 Dock 直接显示所有窗口，更像 Windows 的体验。

ubuntu 20.04 LTS的系统我觉得其简体中文字体都显示得好别扭，能不能换一个好看一些的？

ChatGPT:

是的，Ubuntu 20.04 默认的简体中文字体（通常是 Noto Sans CJK 或 WenQuanYi 字体）确实不太美观，特别是和 Windows 的 微软雅黑 或 macOS 的 苹方 相比，观感会有些生硬。你可以换成更好看的字体，以下是几种推荐方案：

方案 1：使用 Windows 的微软雅黑（Microsoft YaHei）

如果你习惯 Windows 的字体，你可以直接安装 微软雅黑，但需要自己从 Windows 复制过来：

  1. 从 Windows 复制字体

    • 进入 Windows 分区，复制 C:\Windows\Fonts 目录下的 msyh.ttc、msyhbd.ttc、msyhl.ttc。
    • 如果没有 Windows，可以找朋友拷贝或者从 Windows 虚拟机中导出。

  2. 安装字体

    • 创建字体目录：
      mkdir -p ~/.local/share/fonts
    • 复制 .ttc 文件到这个目录：
      cp /你的字体路径/msyh*.ttc ~/.local/share/fonts/
    • 刷新字体缓存：
      fc-cache -fv

  3. 设置微软雅黑为默认字体

    • 在终端执行：
      gsettings set org.gnome.desktop.interface font-name "Microsoft YaHei 11"
    • 你也可以用 gnome-tweaks（见 方案 4）进行更细致的字体调整。

方案 2：安装思源黑体（Source Han Sans）

思源黑体（Source Han Sans）是 Google 和 Adobe 联合推出的免费开源中文字体，字体现代简洁，适合作为系统 UI 字体。

安装方法

Ubuntu 20.04 其实已经自带了 Noto Sans CJK（它和思源黑体是同源的），但你可以安装 Adobe 官方的版本：

sudo apt install fonts-adobe-source-han-sans-cn

然后可以在 gnome-tweaks 里选择 Source Han Sans CN 作为默认字体。

方案 3：安装更优雅的中文字体

如果你觉得 微软雅黑 还是太呆板，可以尝试一些开源的中文字体：

1. 霞鹜文楷（LXGW WenKai）

这是一款 类宋体风格 的中文字体，类似 macOS 里的 华文仿宋，比微软雅黑更有书写感：

sudo apt install fonts-lxgw-wenkai

设置字体后，终端和界面会有更温和的观感。

2. 阿里巴巴普惠体

阿里巴巴官方推出的一款开源字体，比思源黑体更加柔和，适合长期阅读：

  • 下载字体：阿里巴巴普惠体
  • 解压后，把 .ttf 文件放入 ~/.local/share/fonts/
  • 执行 fc-cache -fv 更新字体缓存
  • 用 gnome-tweaks 选择 Alibaba PuHuiTi 作为默认字体

方案 4：使用 GNOME Tweaks（字体调整工具）

如果你希望更灵活地调整字体，可以安装 GNOME Tweaks：

sudo apt install gnome-tweaks

然后：

  1. 打开 Tweaks（中文名：优化）。
  2. 在 字体 选项里，修改界面字体（UI 字体）、文档字体、等宽字体（终端用的字体）。
  3. 选定 Microsoft YaHei、Source Han Sans CN、LXGW WenKai 之一。

方案 5：全局强制更换字体

如果你想在整个 Ubuntu 系统（包括 GTK、QT、Electron 应用）都使用新字体，可以创建一个 ~/.config/fontconfig/fonts.conf 配置文件：

mkdir -p ~/.config/fontconfig
nano ~/.config/fontconfig/fonts.conf

添加以下内容：

<?xml version="1.0"?>
<!DOCTYPE fontconfig SYSTEM "fonts.dtd">
<fontconfig>
    <match target="pattern">
        <test name="family"><string>Noto Sans CJK SC</string></test>
        <edit name="family" mode="assign"><string>Microsoft YaHei</string></edit>
    </match>
</fontconfig>

保存后，运行：

fc-cache -fv

这样，所有使用 Noto Sans CJK 的地方都会被替换成 微软雅黑。

结论：推荐方案

  • 想要 Windows 体验 → 安装 微软雅黑（方案 1）
  • 想要现代简洁风 → 用 思源黑体（方案 2）
  • 想要柔和、仿宋体 → 用 霞鹜文楷（方案 3）
  • 想要更时尚的字体 → 用 阿里巴巴普惠体（方案 3）
  • 想要系统全局更换字体 → 使用 fonts.conf（方案 5）

如果你只是觉得 Ubuntu 默认字体太丑，但不想折腾太多，最简单的方法是：

sudo apt install fonts-adobe-source-han-sans-cn

然后在 Tweaks 里切换字体，体验会大幅提升！

    sudo apt install fonts-adobe-source-code-pro

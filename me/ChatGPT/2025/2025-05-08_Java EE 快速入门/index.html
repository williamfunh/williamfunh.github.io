一、实验内容、要求

项目简介：

实现一个符合本校益禾堂的主营业务流程实际情况的餐饮管理系统，大致功能如下：

  1. 启动首页为功能选项页，包含用户点单、用户取货、添加货存

  2. 进入用户点单页要先登录，从用户处得知电话号码（必须11位），号码存入数据库，根据是否为会员进入商场显示不同信息并记session，一次只允许一个用户点单，上方显示正在点单的用户尾号，根据用户需求搜索商品，进入商品栏，内包含所有商品，和商品货存信息、价格信息，货存不够则无法加入购物车

二、所采用的相关技术规范

JSP：

JSP技术规范是来自于JavaEE规范中的一种，该规范制定了如何开发JSP文件代替响应对象将处理结果写入到响应体的开发流程，同时也规定了Http服务器应该如何调用管理JSP文件。在JSP文件中，可以直接将结果写入到JSP文件，而不需要手写out.print命令。在Http服务器调用JSP文件时，会根据JSP规范要求自动将JSP文件书写的所有内容通过输出流写入到响应体。此外，Tomcat会根据JSP规范将被访问的JSP文件编辑为一个java文件，这个文件是Servlet接口实现类，并将这个java文件编译为class类型。因此，JSP技术规范在Web开发中扮演着重要的角色。

  1. JSP页面可以嵌入Java代码，实现动态内容的生成。

  2. JSP引入了“JSP动作”的XML标签，用来调用内建功能。

  3. 可以创建JSP标签库，然后像使用标准HTML或XML标签一样使用它们。

  4. 在JSP文件中，Java代码应该书写在执行标记符号(<%%>)中，才会被当做Java代码对待。

  5. JSP还支持标记扩展，提供“定制标记”和“标记库”工具，有助于取消标准JSP页的大多数脚本元素。定制标记库是“定制标记处理器”和“标记库描述符”文件的集合。这些标记遵循一定的基本原理，例如标准标记结构、空标记结构需要符合一定的结构、所有标记名、属性和标记前缀都区分大小写、应严格采用层次化嵌套方式等。

Servlet：

Servlet 是 Java Web 应用程序中的组件技术，是运行在服务器端的 Java 应用程序，实现与 JSP 类似的功能。Servlet 本身是一个 Java 类，可以动态地扩展服务器的能力。Web 服务器执行 JSP 文件时，JSP 容器会将其转译为 Servlet 文件，并自动编译解释执行。JSP 中使用到的所有对象都将被转换为 Servlet，然后被执行。Servlet 接收来自客户端的请求，将处理结果返回给客户端。

Servlet 是运行在 Web 服务器上的 Java 程序，作为来自 Web 浏览器或其他 HTTP 客户端的请求与 HTTP 服务器上的数据库和应用程序之间的中间层。所有的 JSP 文件都要事先转换为一个 Servlet 才能运行。

Servlet 在服务器端处理用户信息可以完成以下任务：

  1. 获取客户端浏览器通过 HTML 表单提交的数据及相关信息

  2. 创建并返回对客户端的动态响应页面

  3. 访问服务器端资源，如文件、数据库

  4. 为 JSP 页面准备动态数据，与 JSP 一起协作创建响应页面

Servlet 是在服务器端运行的。Servlet 是 javax.servlet 包中 HttpServlet 类的子类，由服务器完成该子类的创建和初始化。Servlet 生命周期定义了一个 Servlet 如何被加载、初始化，以及它怎样接收请求、响应请求、提供服务。Servlet 生命周期主要由3个过程组成。当首次创建 Servlet 时才会调用 init() 方法，而不是每个用户请求都调用。当用户首次调用对应于 Servlet 的 URL 或再次启动服务器时，就会创建 Servlet。当有客户请求 Servlet 服务时，Web 服务器将启动一个新的线程，在线程中调用 service() 方法响应客户的请求。对于每个请求，Servlet 引擎都会调用此 service() 方法，并把 Servlet 的请求对象和响应对象传递给该方法作为参数。当 Servlet 被卸载时 destroy() 方法被自动调用。该方法用来释放 Servlet 占用的资源，比如数据库连接、Socket 连接等。destroy() 方法只会被调用一次。

JavaScript：

  1. 遵循统一的命名约定：使用驼峰式命名法（camelCase）来命名变量和函数。

  2. 使用注释来解释代码：在关键部分使用注释来解释代码的功能和逻辑。

  3. 避免全局变量：尽量避免使用全局变量，以减少命名冲突和意外修改。

  4. 使用严格模式：在文件的顶部添加”use strict”声明，以启用严格模式，帮助捕获错误。

  5. 避免使用eval()函数：eval()函数可以执行字符串中的JavaScript代码，但容易导致安全问题和难以调试，应尽量避免使用。

  6. 使用==代替===：在比较两个值是否相等时，使用==代替===，因为==会进行类型转换，而===不会。

  7. 使用===而不是==：在比较两个值是否严格相等时，使用===代替==，因为===会检查值和类型是否都相等。

  8. 避免使用with语句：with语句可以改变代码的作用域，容易导致命名冲突和意外的变量修改，应尽量避免使用。

  9. 不要使用for…in循环遍历数组：for…in循环用于遍历对象的属性，而不是数组元素，应使用常规的for循环或forEach()方法来遍历数组。

  10. 使用函数而不是全局变量：将函数定义在全局作用域中，而不是使用全局变量来存储函数，以减少命名冲突和意外修改。

  11. 避免使用arguments.callee：arguments.callee是一个函数，可以引用当前正在执行的函数，但容易导致代码难以理解和维护，应尽量避免使用。

  12. 使用map()和filter()代替for循环：map()和filter()是ES6中引入的箭头函数，可以简化循环操作，提高代码的可读性和可维护性。

三、实验的主要模块及其功能

MVC表现层，承担视图角色；

JSP：搭建与用户交互的界面：首页业务栏、商场查询商品页、商场商品信息页（点单页）、成为会员页、用户购物车页、取货页、添加货存页；

Servlet：通过控制器，分别实现获取当前服务对象用户输入电话设置session，控制服务用户数量为1；

MVC业务逻辑层，承担模型角色：

JavaScript：对用户输入电话号码、取货码、商品名称、商品数量、商品价格进行合理性检验，根据检验结果确定请求数据的传递，从而更好地让控制器选择模型进行处理。

JavaBean：将控制器传递来的请求，使用相应模型，实现决定是否将号码加入数据库，检查用户会员信息，为用户添加会员；

以及实现从数据库获取查询商品信息，添加商品信息到数据库；

实现设置用户点单表（增）、用户点单表删除订单、获取用户点单表、添加交易信息到数据库、通过取货码获取取货信息、取货修改交易信息取货状态

一、理解 Java EE 的核心架构

1.1 Java EE 简介

Java EE（现称 Jakarta EE）是构建企业级应用程序的标准平台，提供了开发分布式、多层次、模块化和可伸缩应用的 API 和运行时环境。

1.2 MVC 架构模式

MVC（Model-View-Controller）是一种设计模式，将应用程序分为三个核心组件：

  • Model（模型）：处理应用程序的数据和业务逻辑。
  • View（视图）：负责数据的呈现，即用户界面。
  • Controller（控制器）：处理用户输入，协调模型和视图之间的交互。

这种分离有助于提高代码的可维护性和可扩展性。

二、项目关键技术点解析

2.1 JSP（JavaServer Pages）

JSP 是一种用于创建动态网页的技术，允许在 HTML 中嵌入 Java 代码。

  • 语法结构：使用 <% ... %> 来嵌入 Java 代码。
  • 作用：主要用于视图层，负责数据的展示。
  • 注意事项：避免在 JSP 中编写过多的业务逻辑，保持页面的简洁性。

2.2 Servlet

Servlet 是运行在服务器端的 Java 程序，用于处理客户端的请求和生成响应。

  • 生命周期方法：
    • init()：初始化方法，在 Servlet 实例化时调用一次。
    • service()：处理请求的方法，每次请求都会调用。
    • destroy()：销毁方法，在 Servlet 被卸载时调用一次。
  • 作用：作为控制器，协调模型和视图之间的交互。

2.3 JavaBean

JavaBean 是一种可重用的组件，遵循特定的编写规范。

  • 特性：
    • 具有无参构造函数。
    • 属性私有，提供公共的 getter 和 setter 方法。
  • 作用：在模型层中，封装业务逻辑和数据操作。

2.4 JDBC 与连接池

JDBC（Java Database Connectivity）是 Java 与数据库交互的 API。

  • 连接池：为了提高性能，使用连接池（如 Apache DBCP、C3P0）来管理数据库连接，避免频繁创建和销毁连接。

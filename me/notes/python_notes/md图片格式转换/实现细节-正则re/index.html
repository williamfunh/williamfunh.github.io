问题description

我在使用jupyter notebook，发现导出的时候，所有图片都是在 ./本目录 下，但是我自己typora里面自定义设置的是把所有图片都放在./assets目录下。
我发现在源代码模式下，对于每个图片，我需要做以下转换才能达到目的，请你帮我把这个过程自动化，用python脚本化：
![png](output_58_0.png) 	->  ![output_58_0](assets/output_58_0.png) 
![png](output_61_0.png) 	->  ![output_61_0](assets/output_61_0.png) 
![png](output_64_0.png) 	->  ![output_64_0](assets/output_64_0.png) 
![png](output_67_1.png)  	->  ![output_64_1](assets/output_67_1.png) 
![png](output_132_0.png)  	->  ![output_132_0](assets/output_132_0.png)

基本上，你希望实现的目标是：

  • 保留(图片的stem)部分（例如 output_58_0.png），
  • 将图片路径从当前目录（./）移动到 assets/ 目录。

格式替换：![png](filename.png) → ![filename](assets/filename.png)

解决

你可以使用以下 Python 脚本来自动化转换过程，将图片路径修改为 assets 目录下的路径。

这个脚本会打开指定的 Markdown 文件，替换所有图片路径，并保存修改后的内容。

以下是具体脚本：

import re

def update_image_paths(md_file_path):
    # 读取 Markdown 文件内容
    with open(md_file_path, 'r', encoding='utf-8') as file:
        content = file.read()

    # 定义正则表达式，用于匹配符合条件的图片语法
    pattern = r'!\[png\]\(([^)]+)\)'
    
    # 替换路径，使图片指向 ./assets 目录并保留原文件名
    new_content = re.sub(pattern, r'![\1](assets/\1)', content)

    # 将替换后的内容写回文件
    with open(md_file_path, 'w', encoding='utf-8') as file:
        file.write(new_content)

    print(f"图片路径更新完成: {md_file_path}")

# 示例：调用函数并传入你的 Markdown 文件路径
update_image_paths('你的Markdown文件路径.md')

解释

  1. 匹配规则：pattern = r'!\[png\]\(([^)]+)\)' 使用reg ex来匹配
    形如 ![png](filename.png) 的语句，捕获 (图片的stem)。
  2. 路径替换：re.sub(pattern, r'![\1](assets/\1)', content) 使用捕获的文件名进行替换，
    将 filename.png 更新为 assets/filename.png。
  3. 文件保存：修改后的内容 会覆盖 原来的 Markdown 文件。

使用方法

  • 将该脚本保存为 .py 文件。
  • 调用 update_image_paths 函数，传入你的 Markdown 文件路径（如 example.md），即可完成图片路径的批量更新。

这样你就不需要手动修改每个图片路径了。

事无巨细讲解re

正则表达式基础

正则表达式（Regex）是一种强大的文本搜索和替换工具，可以帮助你根据一定的模式匹配字符串。它使用了一些特殊字符来表示不同的匹配规则。

1. 固定字符串：!\[png\]

我们要匹配 Markdown 图片语法中的 ![png] 部分。

  • ! 和 [ 是普通字符，表示我们要匹配文本 ![ 和 ]。
  • \[ 和 \]：在正则表达式中，[ 和 ] 是特殊字符，表示字符集的开始和结束，所以我们需要对它们进行“转义”（加上(反斜杠backslash) \）来表示 字面上的方括号。

因此，!\[png\] 就是用来匹配 ![png] 这个固定文本。

2. 匹配圆括号内的文件名：\(([^)]+)\)

在 Markdown 图片语法中，file path或filename是被圆括号 () 包裹的。我们需要匹配圆括号内的filename部分（例如 output_58_0.png）。

  • \( 和 \)：( 和 ) 在正则中也是==特殊字符==，表示捕获组的开始和结束，因此需要加上(反斜杠backslash)来进行转义，表示字面上的圆括号。
  • ([^)]*)：
    1. [^)]：这是一个字符集（即中括号 [] 内部），表示“除了右圆括号 ) 之外的任何字符”。在这里，[^)] 表示匹配“所有非右括号 ) 的字符”。
    2. +：这是一个量词，表示前面的匹配模式可以重复出现一次或多次。我们用 + 表示我们希望捕获文件名的每一个字符（文件名可能有多个字符）。
    3. ()：圆括号是捕获组的意思，它告诉正则表达式要将匹配到的内容提取出来供后续使用。

因此，([^)]*) 就表示捕获圆括号 () 中的内容，也就是文件名部分。比如，它会捕获 output_58_0.png。

3. 总结正则表达式：!\[png\]\(([^)]+)\)

将这些部分合起来：

  • !\[png\] 用来匹配固定的 ![png]。
  • \(([^)]+)\) 用来匹配圆括号中的文件名部分，并捕获它。

最终的正则表达式是：

!\[png\]\(([^)]+)\)

这个表达式的作用是：匹配所有形如 ![png](filename) 的图片语法，并捕获 filename 部分。

4. 替换字符串：![\1](assets/\1)

在替换时，我们需要使用正则表达式的捕获组（也就是我们用小括号 () 捕获的部分）。在正则表达式中，捕获组使用 \1（\2，\3，依此类推）来引用。

  • \1：表示第一个捕获组，也就是我们捕获到的文件名部分（例如 output_58_0.png）。

目标是将 ![png](output_58_0.png) 替换成 ![output_58_0](assets/output_58_0.png)。

  • ![\1]：这里 \1 会被替换为捕获的文件名（例如 output_58_0），所以 ![output_58_0] 就成了新的文本。
  • (assets/\1)：assets/ 是我们要加的路径，\1 会替换成捕获的文件名部分（例如 output_58_0.png），所以这部分变成了 (assets/output_58_0.png)。

5. Python 实现

接下来我们用 Python 实现这一替换过程。我们可以使用 Python 的 re.sub() 函数，它可以找到所有匹配正则表达式的地方，并将其替换为我们指定的字符串。

import re

def update_image_paths(md_file_path):
    # 读取 Markdown 文件内容
    with open(md_file_path, 'r', encoding='utf-8') as file:
        content = file.read()

    # 定义正则表达式，用于匹配符合条件的图片语法
    pattern = r'!\[png\]\(([^)]+)\)'
    
    # 替换路径，使图片指向 ./assets 目录并保留原文件名
    new_content = re.sub(pattern, r'![\1](assets/\1)', content)

    # 将替换后的内容写回文件
    with open(md_file_path, 'w', encoding='utf-8') as file:
        file.write(new_content)

    print(f"图片路径更新完成: {md_file_path}")

# 示例：调用函数并传入你的 Markdown 文件路径
update_image_paths('你的Markdown文件路径.md')

代码解释

  1. with open(md_file_path, 'r', encoding='utf-8') as file:：打开文件并读取其内容。
  2. pattern = r'!\[png\]\(([^)]+)\)'：定义正则表达式，匹配形如 ![png](output_58_0.png) 的语法，并捕获文件名部分。
  3. new_content = re.sub(pattern, r'![\1](assets/\1)', content)：使用 re.sub() 函数，将匹配到的图片路径替换为 ![filename](assets/filename) 格式。
  4. with open(md_file_path, 'w', encoding='utf-8') as file:：将替换后的内容写回文件。

总结

正则表达式的构建分为两部分：

  • 匹配固定的文本部分：!\[png\] 和圆括号 () 内的内容。
  • 捕获文件名部分，替换为新的路径。

在 Python 中，Union 并不是一种具体的data_type，而是一个用于**类型1注解（Type Hints）**的工具，用来表示一个变量可以是many data_types中的一种。它属于 Python 的 typing 模块，是静态类型检查（比如用 mypy）时的辅助工具，不会影响运行时行为。

基本用法

Union 的典型用法是在type_hint中，明确声明一个变量可以是多种类型之一，明确列出一个变量所有可能的类型。例如：

from typing import Union

def process_input(value: Union[int, str]) -> None:
    if isinstance(value, int):
        print("处理整数:", value)
    else:
        print("处理字符串:", value)

这里 value 可以是 int 或 str 类型。

简化写法（Python 3.10+）

Union 可以用更简洁的 | 语法替代(| 是 Union 的语法糖，功能完全相同)：

def process_input(value: int | str) -> None:
    pass

注意事项

  1. 运行时无影响：Union 仅用于类型检查，运行时会被忽略。

    x: Union[int, str] = "hello"
print(type(x))  # 输出 <class 'str'>，而非 Union

  2. 与 Optional 的关系：

    • Optional本质上是 Union 的特例，专门处理“可能为 None”的场景，代码可读性更高。
    • Optional[T] 等价于 Union[T, None]，表示一个值可以是类型 T 或 None。

  3. 动态类型兼容：即使没有 Union，Python 的动态类型依然允许变量赋值为任何类型，但类型检查工具会发出警告。

示例对比

# 动态类型（无type_hint）
def foo(x):
    return x * 2  # x 可以是任何类型，但可能运行时出错

# 带 Union 的type_hint
from typing import Union
def bar(x: Union[int, str]) -> Union[int, str]:
    return x * 2  # 类型检查器会确保 x 是 int 或 str

Optional[T]

  • 作用：表示一个变量可以是类型 T 或 None，是 Union[T, None] 的简写。

  • 示例：

    from typing import Optional

def bar(x: Optional[int]) -> None:
    print(x)
    • x 可以是 int 或 None。

  • 等价写法：

    • Optional[int] ≡ Union[int, None] ≡ int | None（Python 3.10+）。

  • 适用场景：常见于可空参数、返回值或可能缺失的值（如函数默认返回 None 时）。

三者的关系总结

语法 等价形式 用途 Python 版本要求
Union[int, str] `int str` 多类型选择（需显式列出所有类型）
`int str` Union[int, str] 多类型选择的简写
Optional[int] Union[int, None] 表示可空值（T 或 None） 3.5+
`int None` Optional[int] 可空值的简写

关键区别

  1. Optional 专用于 None

    • 它本质上是 Union 的特例，专门处理“可能为 None”的场景，代码可读性更高。
    • 例如，数据库查询可能返回 User 或 None：
      def find_user(id: int) -> Optional[User]:
    ...

  2. 动态类型 vs 静态检查

    • 这些注解不会影响运行时行为，但类型检查工具（如 mypy）会据此验证代码。

示例对比

from typing import Union, Optional

# 使用 Union
def func1(x: Union[int, str]) -> Union[int, str]:
    return x

# 使用 | （Python 3.10+）
def func2(x: int | str) -> int | str:
    return x

# 使用 Optional
def func3(x: Optional[int]) -> Optional[int]:
    return x

# 使用 | 表示 Optional
def func4(x: int | None) -> int | None:
    return x

如何选择？

  • Python 3.10+：优先用 |（如 int | str 或 int | None）。
  • 需要兼容旧版本：用 Union 或 Optional。
  • 可读性：如果是“可能为 None”的场景，Optional[T] 更语义化。

如果有更复杂的需求（如嵌套类型），可以组合使用这些工具，例如：

from typing import List, Union

def handle_data(data: List[Union[int, str]]) -> Optional[List[str]]:
    ...

注释标记 Comment marks

在 Python（以及其他编程语言）中，TODO 是一种常见的注释标记，用于在代码中临时标注需要后续完成或改进的地方。它本身不是 Python 的语法特性，而是一种开发者约定的注释规范。

作用

  1. 标记未完成的任务
    在开发过程中，你可能暂时跳过某些功能或需要后续补充代码，可以用 TODO 标记提醒自己或团队成员。

  2. 代码审查或协作提示
    在团队项目中，TODO 可以告知其他开发者这里有待处理的工作（例如优化、修复或补充逻辑）。

  3. 工具支持
    许多 IDE（如 PyCharm、VSCode）或代码分析工具（如 pylint）会自动识别 TODO 注释，并将其汇总到任务列表（Task List）中，方便跟踪。

示例

def calculate_total(items):
    # TODO: 处理折扣逻辑
    total = sum(items)
    return total

# FIXME: 这里的异常处理需要更严谨
def load_data(filename):
    try:
        with open(filename) as f:
            return f.read()
    except FileNotFoundError:
        pass

常见标记类型

除了 TODO，还有其他类似的注释标记：

  • FIXME: 表示需要修复的问题（通常比 TODO 更紧急）。
  • NOTE: 说明代码的特殊意图或细节。
  • HACK: 标记临时或不够优雅的解决方案。

IDE 支持

  • PyCharm/VSCode: 会在代码底部或单独面板中列出所有 TODO 注释。
  • 命令行工具: 可通过 grep 或 pylint 查找 TODO：
    grep -r "TODO" ./

注意事项

  1. 不要滥用
    过多的 TODO 会导致代码维护困难，完成后应及时删除或处理。

  2. 明确描述
    好的 TODO 应说明具体任务，例如：

    # TODO: 改用更高效的算法（参考 Issue #123）

总结来说，TODO 是一种提高代码可维护性的实践，帮助开发者管理未完成的任务。
